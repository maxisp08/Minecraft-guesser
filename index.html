How to play

  1. Pick Mob, Block or Item at the top.
  2. Type a name and pick it from the list. The list already shows its properties.
  3. Each guess shows how close you are: green match · yellow partly right · red wrong · ↑ the answer is higher/newer · ↓ lower/older.
  4. Stuck? 🔎 Hint gives up to 3 clues: two indirect clues, then how long the name is. 💡 Reveal shows the answer (counts as a loss).
  5. After a round press ▶ Next round or Enter. ↺ New starts a new round any time, 📱/💻 switches between card and table view.

Modes

  • 🎲 Just guess – free play without a timer. The search bar is green.
  • ⏱ Competition – Time limit: as many as possible before the timer ends. Target count: a set number as fast as possible. Choose All or one area. Results are kept in 📜 History. The search bar turns gold.
  • 🎯 Challenges – Easy 3, Medium 5, Hard 8 correct in 10 minutes. All 3 hints are allowed. Grade by time used: S ≤ 30 % · A ≤ 45 % · B ≤ 60 % · C ≤ 75 % · D in time · F not finished. The search bar turns turquoise.
  • ⚔️ Multiplayer – create a lobby, share the 4-letter code, and play live against up to 7 friends. Everyone gets the same answers in the same order. 🏁 Race: first to X correct · ⏱ Time limit: most correct · ⛳ Fewest tries: fewest tries for X answers. Hints are off; ⏭ Skip gives a small penalty (Race +10 s · Time limit 5 s locked · Fewest tries +3). Friends just open the same website — no account needed. 📊 Battle stats (wins, records, head-to-head) are kept in this browser. The search bar turns purple.
  • 📊 Statistics – streaks, win rate and averages per area, or All combined. Saved in this browser.
What the columns mean

Categories follow the Minecraft Wiki: mobs by behavior (Passive / Neutral / Hostile / Boss) and mob type, blocks and items by Creative inventory tab. Craftable = has a crafting recipe. Recipe = Crafting, Smelting or None. Blast resistance = how well a block withstands explosions. Renewable = can be obtained again and again in Survival. Introduced = first Java version with update name and release month.

Blocks that exist in several wood types, colors or copper stages are one entry (e.g. "Wooden Fence", "Wool"). Polished, chiseled, cracked, cut, smooth and mossy versions are left out; only the base block is kept (e.g. "Nether Bricks"). Tools, weapons and armor only in Diamond and Netherite. Values checked against the game data of Java 26.1; data up to Java 26.3 (Sep 2026). HP and newest content may be slightly off.
